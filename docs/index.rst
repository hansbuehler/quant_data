openqai.core documentation
=======================

The **openqai.core** packages aims to provide standardized tools to access and process data from various sources.
The purpose is to ensure ML/AI models developed in quantitative finance are using robust benchmark data sets
with transparent data cleaning, filtering and encrichment which can be re-used by other researchers.

The main github is located at [``https://github.com/hansbuehler/quant_data/``](https://github.com/hansbuehler/quant_data/).

Please refer to installation instructions there.
