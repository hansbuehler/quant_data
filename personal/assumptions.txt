About Kalman_filter_first_clean.ipynb :
FOR ONE OPTION:
Get trades + quotes.
Both get assigned an uncertainty.
Quotes: proportional to bid ask spread
Trades: proportional to last bid-ask spread, with a smaller constant.

Observed price of quotes: microprice
Observed price of trade: trade price. (can be refined to see if it was over mid-price or under, to determine maybe a fairer observation)
Both in the kalman filter
Do Kalman filter on prices.

Implied vol:
Take spot data for trades, and filter for valid ones.
Use last price traded as an estimate of the spot. (Improvement possible?)
Then use this spot to compute implied vol.
DO Kalman filter on implied vol. uncertainty now proportional to bid-ask spread of IV space.


fixed_forward_window_last:
for a trade that happens at t, we take the window between t and t+250ms and we take the last quote available.
So if we have one at t, one at t+50ms and one at t+200ms we will tkae the one at t+200.




About matching trades and quotes:
We do it in a dataclass to cache the matching. 
We can configure paramters for forward looking and backward looking. Default is 250ms each.
If we find none, we fill with null (then we can post-process it how we want).



About implied forward:
cdxcore uses normalized price (by implied forward) so we computethe implied forward
instead of the spot. (it led to errors, mainly because of the conversion between put anc calls)
SO we do everything with the forward.
Also, this takes out the need to use the spot datset, which in itself may be inaccurate because
it also has trades and quotes and maybe shoudl do KF on it to estimate true etc...
